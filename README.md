# Developer Portfolio

A responsive personal developer portfolio built using semantic HTML and CSS.

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Responsive Media Queries

## Run Locally

1. Clone the repository.
2. Open the devfolio folder.
3. Open `index.html` in a browser.

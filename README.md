# Kundana's Developer Portfolio

## About

A responsive personal developer portfolio built with semantic HTML5 and CSS3. It showcases my introduction, projects, and contact information.

## Technologies Used

* HTML5
* CSS3
* Flexbox
* CSS Grid
* Responsive media queries
* GitHub Pages

## Run Locally

1. Clone this repository:

   `git clone https://github.com/kundana0905/devfolio.git`

2. Open the project folder:

   `cd devfolio`

3. Open `index.html` in your browser, or use the Live Server extension in VS Code.
